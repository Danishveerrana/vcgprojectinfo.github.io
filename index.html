How It Works
Voice → Command → Shape

The VCG pipeline has three stages:


1. Capture. Your microphone streams audio to the SpeechRecognizer via Google's Speech API. Even numbers like "ten" are correctly converted to 10.


2. Parse. The recognized text runs through a command parser that maps natural language to drawing actions — draw circle, undo, clear, save.


3. Render. Python's turtle module executes the command in real-time. The canvas updates instantly and state is logged for debugging.
